## Uygulama Rehberi

### GroupDocs.Conversion Kullanarak DWF'yi HTML'ye Nasıl Dönüştürülür?
`Converter`, dönüşüm için kaynak dosyayı temsil eden temel sınıftır.  
`Convert` metodu dönüşüm sürecini yürütür ve sonucu belirtilen hedefe yazar.  
`WebConvertOptions`, sayfa boyutu, görüntü kalitesi ve CSS gömme gibi HTML çıktı ayarlarını belirler.

`Converter` sınıfı ile DWF dosyanızı yükleyin ve `Convert` metodunu çağırın, API'ye HTML üretmesini söyleyen bir `WebConvertOptions` nesnesi geçirin. Bu tek satırlık çağrı rasterleştirme, vektör çevirisi ve stil sayfası oluşturmayı otomatik olarak yönetir.

`WebConvertOptions`, çıktı formatını ve sayfa boyutu, görüntü kalitesi ve CSS gömme gibi isteğe bağlı ayarları tanımlar.

```csharp
string inputFilePath = Path.Combine("YOUR_DOCUMENT_DIRECTORY", "sample.dwf");
string outputFolder = "YOUR_OUTPUT_DIRECTORY";
string outputFile = Path.Combine(outputFolder, "dwf-converted-to.html");
```  

### Adım 1: Giriş ve Çıkış Yollarını Tanımlayın
Kaynak DWF'nin nerede bulunduğunu ve oluşan HTML'nin nereye kaydedileceğini belirtin.

```csharp
using (var converter = new Converter(inputFilePath))
{
    // Initialize options to convert to HTML format
    var options = new WebConvertOptions();
    
    // Perform the conversion and save as an HTML file
    converter.Convert(outputFile, options);
}
```  

### Adım 2: Dönüşümü Gerçekleştirin
`converter.Convert` metodunu `WebConvertOptions` ile çağırın. Metod, sonucu doğrudan diske akıtarak, 500 MB'den büyük dosyalarda bile düşük bellek kullanımı sağlar.

## Performans Hususları
Büyük CAD çizimlerini dönüştürürken aşağıdaki ipuçlarını aklınızda tutun:

- **Kaynak Optimizasyonu** – RAM kullanımını 256 MB ile sınırlamak için `converter.Options.MemoryLimit` (dönüştürücünün tahsis edebileceği maksimum belleği kısıtlar) özelliğini etkinleştirin.  
- **Toplu İşleme** – I/O yükünü azaltmak için dosyaları 10–20'lik gruplara ayırın.  
- **Asenkron Çalıştırma** – UI iş parçacıklarının yanıt vermesini sağlamak için dönüşüm çağrısını `Task.Run` içinde sarın.  
- **Paralellik** – toplu işleri hızlandırmak için `converter.Options.ThreadCount` (dönüşüm sırasında aynı anda kullanılan iş parçacığı sayısını belirler) değerini artırın.  

Bu uygulamaları izlemek, tipik sunucu limitleri içinde kalmanızı ve hızlı dönüşüm sürelerini korumanızı sağlar.

## Yaygın Sorunlar ve Çözümler
- **Çıktıda Boş Sayfalar** – DWF dosyasının şifre korumalı olmadığını doğrulayın; gerekirse `converter.LoadOptions.Password` (şifreli dosyalar için şifre sağlamanızı sağlar) kullanın.  
- **Eksik Yazı Tipleri** – gerekli yazı tiplerini kaynak DWF'ye gömün veya `converter.Options.FontsPath` (render için gereken yazı tiplerini içeren dizini belirtir) aracılığıyla bir yazı tipi klasörü sağlayın.  
- **Bellek Dışı Hatalar** – akış modunu etkinleştirin (`converter.Options.UseStream = true`; `UseStream`, dosyaları parçalara bölerek işlemek ve bellek kullanımını azaltmak için akış modunu etkinleştirir) ve dosyayı parçalara bölerek işleyin.
