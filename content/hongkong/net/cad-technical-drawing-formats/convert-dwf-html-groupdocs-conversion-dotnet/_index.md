## 實作指南

### 如何使用 GroupDocs.Conversion 將 DWF 轉換為 HTML？
`Converter` 是代表來源檔案的核心類別。  
`Convert` 方法執行轉換程序，並將結果寫入指定的目的地。  
`WebConvertOptions` 指定 HTML 輸出設定，例如頁面大小、影像品質與 CSS 嵌入。

使用 `Converter` 類別載入 DWF 檔案，然後呼叫 `Convert` 方法，傳入 `WebConvertOptions` 物件以指示 API 產生 HTML。此單行呼叫會自動處理光柵化、向量轉換與樣式表產生。

`WebConvertOptions` 定義輸出格式及可選設定，如頁面大小、影像品質與 CSS 嵌入。

```csharp
string inputFilePath = Path.Combine("YOUR_DOCUMENT_DIRECTORY", "sample.dwf");
string outputFolder = "YOUR_OUTPUT_DIRECTORY";
string outputFile = Path.Combine(outputFolder, "dwf-converted-to.html");
```  

### 步驟 1：定義輸入與輸出路徑
指定來源 DWF 檔案所在位置以及產生的 HTML 檔案要儲存的路徑。

```csharp
using (var converter = new Converter(inputFilePath))
{
    // Initialize options to convert to HTML format
    var options = new WebConvertOptions();
    
    // Perform the conversion and save as an HTML file
    converter.Convert(outputFile, options);
}
```  

### 步驟 2：執行轉換
使用 `WebConvertOptions` 呼叫 `converter.Convert`。此方法會直接將結果串流寫入磁碟，即使檔案超過 500 MB，也能保持低記憶體使用量。

## 效能考量
轉換大型 CAD 圖紙時，請留意以下建議：

- **資源最佳化** – 啟用 `converter.Options.MemoryLimit`（限制轉換器可分配的最大記憶體）以將 RAM 使用量上限設為 256 MB。  
- **批次處理** – 將檔案分組為 10–20 個一批，以減少 I/O 開銷。  
- **非同步執行** – 將轉換呼叫包在 `Task.Run` 中，以保持 UI 執行緒的回應性。  
- **平行處理** – 增加 `converter.Options.ThreadCount`（決定轉換期間同時使用的執行緒數量）以加速批次作業。  

遵循這些做法可確保在典型伺服器限制內，同時維持快速的轉換速度。

## 常見問題與解決方案
- **輸出空白頁面** – 確認 DWF 檔案未受密碼保護；如有需要，可使用 `converter.LoadOptions.Password`（提供加密檔案的密碼）。  
- **缺少字型** – 在來源 DWF 中嵌入必要字型，或透過 `converter.Options.FontsPath`（指定渲染所需字型的目錄）提供字型資料夾。  
- **記憶體不足錯誤** – 啟用串流模式 (`converter.Options.UseStream = true`；`UseStream` 會以區塊方式處理檔案，降低記憶體使用)。
