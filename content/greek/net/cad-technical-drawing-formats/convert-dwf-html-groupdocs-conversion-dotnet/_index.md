## Οδηγός Υλοποίησης

### Πώς να Μετατρέψετε DWF σε HTML Χρησιμοποιώντας το GroupDocs.Conversion;
`Converter` είναι η βασική κλάση που αντιπροσωπεύει το αρχείο προέλευσης για μετατροπή.  
`Convert` μέθοδος εκτελεί τη διαδικασία μετατροπής και γράφει το αποτέλεσμα στον καθορισμένο προορισμό.  
`WebConvertOptions` καθορίζει τις ρυθμίσεις εξόδου HTML όπως μέγεθος σελίδας, ποιότητα εικόνας και ενσωμάτωση CSS.

Φορτώστε το αρχείο DWF με την κλάση `Converter` και καλέστε τη μέθοδο `Convert`, περνώντας ένα αντικείμενο `WebConvertOptions` που λέει στο API να παράγει HTML. Αυτή η κλήση μίας γραμμής διαχειρίζεται αυτόματα τη ραστεροποίηση, τη μετάφραση διανυσμάτων και τη δημιουργία φύλλων στυλ.

`WebConvertOptions` ορίζει τη μορφή εξόδου και προαιρετικές ρυθμίσεις όπως μέγεθος σελίδας, ποιότητα εικόνας και ενσωμάτωση CSS.

```csharp
string inputFilePath = Path.Combine("YOUR_DOCUMENT_DIRECTORY", "sample.dwf");
string outputFolder = "YOUR_OUTPUT_DIRECTORY";
string outputFile = Path.Combine(outputFolder, "dwf-converted-to.html");
```  

### Βήμα 1: Ορισμός Διαδρομών Εισόδου και Εξόδου
Καθορίστε πού βρίσκεται το αρχείο DWF προέλευσης και πού πρέπει να αποθηκευτεί το παραγόμενο HTML.

```csharp
using (var converter = new Converter(inputFilePath))
{
    // Initialize options to convert to HTML format
    var options = new WebConvertOptions();
    
    // Perform the conversion and save as an HTML file
    converter.Convert(outputFile, options);
}
```  

### Βήμα 2: Εκτέλεση της Μετατροπής
Κληθείτε `converter.Convert` με το `WebConvertOptions`. Η μέθοδος μεταδίδει το αποτέλεσμα απευθείας στο δίσκο, διατηρώντας τη χρήση μνήμης χαμηλή ακόμη και για αρχεία μεγαλύτερα από 500 MB.

## Σκέψεις για την Απόδοση
Κατά τη μετατροπή μεγάλων CAD σχεδίων, λάβετε υπόψη τις παρακάτω συμβουλές:

- **Βελτιστοποίηση Πόρων** – ενεργοποιήστε `converter.Options.MemoryLimit` (που περιορίζει τη μέγιστη μνήμη που μπορεί να εκχωρήσει ο μετατροπέας) για να περιορίσετε τη χρήση RAM στα 256 MB.  
- **Επεξεργασία σε Παρτίδες** – ομαδοποιήστε αρχεία σε παρτίδες των 10–20 για ελαχιστοποίηση του φόρτου I/O.  
- **Ασύγχρονη Εκτέλεση** – τυλίξτε την κλήση μετατροπής σε `Task.Run` για να διατηρήσετε τα UI νήματα ανταποκρινόμενα.  
- **Παραλληλισμός** – αυξήστε το `converter.Options.ThreadCount` (που καθορίζει πόσα νήματα χρησιμοποιούνται ταυτόχρονα κατά τη μετατροπή) για να επιταχύνετε τις παρτίδες εργασιών.

Ακολουθώντας αυτές τις πρακτικές διασφαλίζετε ότι παραμένετε εντός των τυπικών ορίων του διακομιστή ενώ διατηρείτε γρήγορους χρόνους μετατροπής.

## Συνηθισμένα Προβλήματα και Λύσεις
- **Κενές Σελίδες στην Έξοδο** – βεβαιωθείτε ότι το αρχείο DWF δεν είναι προστατευμένο με κωδικό· χρησιμοποιήστε `converter.LoadOptions.Password` (που σας επιτρέπει να δώσετε κωδικό για κρυπτογραφημένα αρχεία) αν χρειάζεται.  
- **Λείπουν Γραμματοσειρές** – ενσωματώστε τις απαιτούμενες γραμματοσειρές στο αρχείο DWF προέλευσης ή παρέχετε φάκελο γραμματοσειρών μέσω `converter.Options.FontsPath` (που καθορίζει τον κατάλογο που περιέχει τις γραμματοσειρές που χρειάζονται για την απόδοση).  
- **Σφάλματα Έλλειψης Μνήμης** – ενεργοποιήστε τη λειτουργία streaming (`converter.Options.UseStream = true`; `UseStream` ενεργοποιεί τη λειτουργία streaming για επεξεργασία αρχείων σε τμήματα, μειώνοντας τη χρήση μνήμης) για επεξεργασία του αρχείου σε τμήματα.
