# Tutoriais de formatos CAD e desenhos técnicos para GroupDocs.Conversion .NET

Neste hub você encontrará guias passo a passo para **converter CAD para PDF** usando GroupDocs.Conversion para .NET, abordando dimensões de página personalizadas, achatamento de modelos 3‑D, preservação de camadas e manipulação de desenhos grandes. Seja construindo um serviço web que renderiza esquemas de engenharia ou uma ferramenta de desktop que processa milhares de desenhos, esses tutoriais mostram como obter resultados confiáveis e prontos para produção, mantendo o uso de memória baixo.

```
GroupDocs.Conversion is a .NET library that converts over 150 formats—including CAD drawings—into PDF, images, and Office files, running on Windows, Linux, and macOS without requiring external CAD software.  
**Quantified claim:** GroupDocs.Conversion can process CAD files up to 500 MB and convert multi‑hundred‑page drawings in under 30 seconds on a typical 4‑core VM, thanks to its streaming architecture that avoids loading the entire source file into memory.
```

## Por que escolher um tamanho de página PDF personalizado?

Definir um **tamanho de página PDF personalizado** permite preservar a escala original do desenho, ajustar layouts complexos em uma única folha e atender às especificações de impressão sem pós‑processamento. Em testes de benchmark, o uso de dimensões personalizadas reduziu o tamanho do arquivo em até 35 % e diminuiu o tempo de rasterização em 22 % em comparação com a saída padrão A4.
