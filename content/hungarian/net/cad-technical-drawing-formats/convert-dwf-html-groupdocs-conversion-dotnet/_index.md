## Implementációs útmutató

### Hogyan konvertáljuk a DWF-et HTML-re a GroupDocs.Conversion segítségével?
`Converter` a fő osztály, amely a forrásfájlt képviseli a konverzióhoz.  
A `Convert` metódus végrehajtja a konverziós folyamatot, és az eredményt a megadott célhelyre írja.  
A `WebConvertOptions` meghatározza a HTML kimeneti beállításait, például az oldalméretet, a képminőséget és a CSS beágyazását.

Töltse be a DWF fájlt a `Converter` osztállyal, és hívja meg a `Convert` metódust, egy `WebConvertOptions` objektumot átadva, amely azt mondja az API-nak, hogy HTML-t állítson elő. Ez az egy‑soros hívás automatikusan kezeli a rasterizációt, a vektor‑átalakítást és a stíluslap‑generálást.

`WebConvertOptions` meghatározza a kimeneti formátumot és opcionális beállításokat, például az oldalméretet, a képminőséget és a CSS beágyazását.

```csharp
string inputFilePath = Path.Combine("YOUR_DOCUMENT_DIRECTORY", "sample.dwf");
string outputFolder = "YOUR_OUTPUT_DIRECTORY";
string outputFile = Path.Combine(outputFolder, "dwf-converted-to.html");
```  

### 1. lépés: Bemeneti és kimeneti útvonalak meghatározása
Adja meg, hogy a forrás DWF hol található, és hová kell menteni a létrejövő HTML‑t.

```csharp
using (var converter = new Converter(inputFilePath))
{
    // Initialize options to convert to HTML format
    var options = new WebConvertOptions();
    
    // Perform the conversion and save as an HTML file
    converter.Convert(outputFile, options);
}
```  

### 2. lépés: A konverzió végrehajtása
Hívja meg a `converter.Convert`‑t a `WebConvertOptions`‑szel. A metódus közvetlenül a lemezre streameli az eredményt, így a memóriahasználat alacsony marad még 500 MB‑nál nagyobb fájlok esetén is.

## Teljesítményfontosságú szempontok
Nagy CAD rajzok konvertálásakor tartsa szem előtt a következő tippeket:

- **Erőforrás-optimalizálás** – engedélyezze a `converter.Options.MemoryLimit`‑et (amely korlátozza a konverter által lefoglalható maximális memóriát), hogy a RAM használatot 256 MB‑ra korlátozza.  
- **Kötegelt feldolgozás** – csoportosítsa a fájlokat 10–20-as kötegekbe az I/O terhelés csökkentése érdekében.  
- **Aszinkron végrehajtás** – csomagolja a konverzióhívást `Task.Run`‑ba, hogy a UI szálak reagálók maradjanak.  
- **Párhuzamosság** – növelje a `converter.Options.ThreadCount`‑et (amely meghatározza, hány szál használatos párhuzamosan a konverzió során), hogy felgyorsítsa a kötegelt feladatokat.  

Ezeknek a gyakorlatoknak a követése biztosítja, hogy a tipikus szerverkorlátokon belül maradjon, miközben gyors konverziós időket tart fenn.

## Gyakori problémák és megoldások
- **Üres oldalak a kimenetben** – ellenőrizze, hogy a DWF fájl nincs jelszóval védve; ha szükséges, használja a `converter.LoadOptions.Password`‑t (amely lehetővé teszi jelszó megadását a titkosított fájlokhoz).  
- **Hiányzó betűtípusok** – ágyazza be a szükséges betűtípusokat a forrás DWF‑be, vagy adjon meg egy betűtípus mappát a `converter.Options.FontsPath` segítségével (amely megadja a rendereléshez szükséges betűtípusokat tartalmazó könyvtárat).  
- **Memóriahiány hibák** – engedélyezze a streaming módot (`converter.Options.UseStream = true`; a `UseStream` streaming módot aktiválja, hogy a fájlt darabokban dolgozza fel, csökkentve a memóriahasználatot), hogy a fájlt darabokban dolgozza fel.
