# CAD и технические форматы чертежей: учебники для GroupDocs.Conversion .NET

В этом центре вы найдёте пошаговые руководства по **конвертации CAD в PDF** с использованием GroupDocs.Conversion для .NET, охватывающие пользовательские размеры страниц, уплощение 3‑D моделей, сохранение слоёв и работу с большими чертежами. Независимо от того, создаёте ли вы веб‑службу, отображающую инженерные схемы, или настольную утилиту, пакетирующую тысячи чертежей, эти учебники покажут, как получить надёжные, готовые к продакшну результаты при низком потреблении памяти.

```
GroupDocs.Conversion is a .NET library that converts over 150 formats—including CAD drawings—into PDF, images, and Office files, running on Windows, Linux, and macOS without requiring external CAD software.  
**Quantified claim:** GroupDocs.Conversion can process CAD files up to 500 MB and convert multi‑hundred‑page drawings in under 30 seconds on a typical 4‑core VM, thanks to its streaming architecture that avoids loading the entire source file into memory.
```

## Почему стоит выбирать пользовательский размер страницы PDF?

Установка **пользовательского размера страницы PDF** позволяет сохранить оригинальный масштаб чертежа, разместить сложные макеты на одном листе и соответствовать требованиям типографии без постобработки. В тестах производительности использование пользовательских размеров уменьшило размер файла до 35 % и сократило время растеризации на 22 % по сравнению с выводом по умолчанию A4.
