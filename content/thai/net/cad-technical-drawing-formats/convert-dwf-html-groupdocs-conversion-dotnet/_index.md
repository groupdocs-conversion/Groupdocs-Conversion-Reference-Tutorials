## คู่มือการใช้งาน

### วิธีแปลง DWF เป็น HTML ด้วย GroupDocs.Conversion?
`Converter` คือคลาสหลักที่แทนไฟล์ต้นทางสำหรับการแปลง.  
`Convert` method ทำการแปลงและเขียนผลลัพธ์ไปยังตำแหน่งที่กำหนด.  
`WebConvertOptions` ระบุการตั้งค่าเอาต์พุต HTML เช่น ขนาดหน้า, คุณภาพภาพ, และการฝัง CSS.

โหลดไฟล์ DWF ของคุณด้วยคลาส `Converter` แล้วเรียกเมธอด `Convert` โดยส่งอ็อบเจ็กต์ `WebConvertOptions` ที่บอก API ให้สร้าง HTML การเรียกแบบบรรทัดเดียวนี้จัดการการเรสเตอร์ไลเซชัน, การแปลงเวกเตอร์, และการสร้างสไตล์ชีตโดยอัตโนมัติ.

`WebConvertOptions` กำหนดรูปแบบเอาต์พุตและการตั้งค่าเพิ่มเติม เช่น ขนาดหน้า, คุณภาพภาพ, และการฝัง CSS.

```csharp
string inputFilePath = Path.Combine("YOUR_DOCUMENT_DIRECTORY", "sample.dwf");
string outputFolder = "YOUR_OUTPUT_DIRECTORY";
string outputFile = Path.Combine(outputFolder, "dwf-converted-to.html");
```  

### ขั้นตอนที่ 1: กำหนดเส้นทางอินพุตและเอาต์พุต
ระบุที่ตั้งของไฟล์ DWF ต้นทางและที่ที่ไฟล์ HTML ที่ได้ควรบันทึก.

```csharp
using (var converter = new Converter(inputFilePath))
{
    // Initialize options to convert to HTML format
    var options = new WebConvertOptions();
    
    // Perform the conversion and save as an HTML file
    converter.Convert(outputFile, options);
}
```  

### ขั้นตอนที่ 2: ดำเนินการแปลง
เรียก `converter.Convert` พร้อมกับ `WebConvertOptions`. เมธอดนี้สตรีมผลลัพธ์โดยตรงไปยังดิสก์ ทำให้การใช้หน่วยความจำน้อยแม้ไฟล์ขนาดใหญ่กว่า 500 MB.

## การประยุกต์ใช้งานจริง
การแปลง DWF เป็น HTML เปิดโอกาสให้กับหลายสถานการณ์จริง:

1. **การนำเสนอสถาปัตยกรรม** – ฝังแผนผังชั้นแบบโต้ตอบในพอร์ทัลที่ให้ลูกค้าเข้าถึง.  
2. **เอกสารวิศวกรรม** – แชร์แผนผังละเอียดผ่านอินทราเน็ตโดยไม่ต้องติดตั้งตัวดู CAD.  
3. **แดชบอร์ดการจัดการโครงการ** – แสดงภาพสแนปช็อตของการออกแบบพร้อมรายการงานและไทม์ไลน์.  

กรณีการใช้งานเหล่านี้ช่วยปรับปรุงการทำงานร่วมกันและลดความจำเป็นในการมีซอฟต์แวร์เฉพาะบนเครื่องของผู้มีส่วนได้ส่วนเสียแต่ละคน.

## พิจารณาด้านประสิทธิภาพ
เมื่อแปลงภาพวาด CAD ขนาดใหญ่ ให้คำนึงถึงเคล็ดลับต่อไปนี้:

- **การเพิ่มประสิทธิภาพทรัพยากร** – เปิดใช้งาน `converter.Options.MemoryLimit` (ซึ่งจำกัดหน่วยความจำสูงสุดที่คอนเวอร์เตอร์สามารถจัดสรร) เพื่อจำกัดการใช้ RAM ที่ 256 MB.  
- **การประมวลผลเป็นชุด** – จัดกลุ่มไฟล์เป็นชุดขนาด 10–20 เพื่อลดภาระ I/O.  
- **การดำเนินการแบบอะซิงโครนัส** – ห่อการเรียกแปลงด้วย `Task.Run` เพื่อให้เธรด UI ตอบสนอง.  
- **การทำงานแบบขนาน** – เพิ่มค่า `converter.Options.ThreadCount` (ซึ่งกำหนดจำนวนเธรดที่ใช้พร้อมกันระหว่างการแปลง) เพื่อเร่งความเร็วของงานเป็นชุด.  

การปฏิบัติตามแนวทางเหล่านี้จะทำให้คุณอยู่ในขอบเขตของเซิร์ฟเวอร์ทั่วไปพร้อมรักษาความเร็วในการแปลงที่รวดเร็ว.

## ปัญหาทั่วไปและวิธีแก้
- **หน้าว่างในผลลัพธ์** – ตรวจสอบว่าไฟล์ DWF ไม่ได้ถูกป้องกันด้วยรหัสผ่าน; ใช้ `converter.LoadOptions.Password` (ซึ่งให้คุณระบุรหัสผ่านสำหรับไฟล์ที่เข้ารหัส) หากจำเป็น.  
- **ฟอนต์หาย** – ฝังฟอนต์ที่จำเป็นในไฟล์ DWF ต้นทางหรือระบุโฟลเดอร์ฟอนต์ผ่าน `converter.Options.FontsPath` (ซึ่งระบุไดเรกทอรีที่มีฟอนต์ที่จำเป็นสำหรับการเรนเดอร์).  
- **ข้อผิดพลาด Out‑of‑Memory** – เปิดโหมดสตรีมมิ่ง (`converter.Options.UseStream = true`; `UseStream` เปิดใช้งานโหมดสตรีมมิ่งเพื่อประมวลผลไฟล์เป็นชิ้น ๆ ลดการใช้หน่วยความจำ) เพื่อประมวลผลไฟล์เป็นชิ้น.
