# Cara Mengonversi DWF ke HTML Menggunakan GroupDocs.Conversion untuk .NET

Pada akhir tutorial Anda akan dapat menyematkan gambar CAD yang kaya di aplikasi web mana pun tanpa memerlukan penampil khusus.

## Panduan Implementasi

### Cara Mengonversi DWF ke HTML Menggunakan GroupDocs.Conversion?
`Converter` adalah kelas inti yang mewakili file sumber untuk konversi.  
Metode `Convert` mengeksekusi proses konversi dan menulis hasil ke tujuan yang ditentukan.  
`WebConvertOptions` menentukan pengaturan output HTML seperti ukuran halaman, kualitas gambar, dan penyematan CSS.

Muat file DWF Anda dengan kelas `Converter` dan panggil metode `Convert`, dengan memberikan objek `WebConvertOptions` yang memberi tahu API untuk menghasilkan HTML. Panggilan satu baris ini menangani rasterisasi, terjemahan vektor, dan pembuatan stylesheet secara otomatis.

`WebConvertOptions` mendefinisikan format output dan pengaturan opsional seperti ukuran halaman, kualitas gambar, dan penyematan CSS.

```csharp
string inputFilePath = Path.Combine("YOUR_DOCUMENT_DIRECTORY", "sample.dwf");
string outputFolder = "YOUR_OUTPUT_DIRECTORY";
string outputFile = Path.Combine(outputFolder, "dwf-converted-to.html");
```  

### Langkah 1: Tentukan Jalur Input dan Output
Tentukan di mana DWF sumber berada dan di mana HTML hasil konversi harus disimpan.

```csharp
using (var converter = new Converter(inputFilePath))
{
    // Initialize options to convert to HTML format
    var options = new WebConvertOptions();
    
    // Perform the conversion and save as an HTML file
    converter.Convert(outputFile, options);
}
```  

### Langkah 2: Jalankan Konversi
Panggil `converter.Convert` dengan `WebConvertOptions`. Metode ini men-stream hasil langsung ke disk, menjaga penggunaan memori rendah bahkan untuk file yang lebih besar dari 500 MB.

## Pertimbangan Kinerja
Saat mengonversi gambar CAD besar, perhatikan tips berikut:

- **Optimisasi Sumber Daya** – aktifkan `converter.Options.MemoryLimit` (yang membatasi memori maksimum yang dapat dialokasikan konverter) untuk membatasi penggunaan RAM pada 256 MB.  
- **Pemrosesan Batch** – kelompokkan file menjadi batch berukuran 10–20 untuk meminimalkan overhead I/O.  
- **Eksekusi Asinkron** – bungkus panggilan konversi dalam `Task.Run` untuk menjaga thread UI tetap responsif.  
- **Paralelisme** – tingkatkan `converter.Options.ThreadCount` (yang menentukan berapa banyak thread yang digunakan secara bersamaan selama konversi) untuk mempercepat pekerjaan batch.  

Mengikuti praktik ini memastikan Anda tetap dalam batas server tipikal sambil mempertahankan waktu konversi yang cepat.

## Masalah Umum dan Solusinya
- **Halaman Kosong pada Output** – pastikan file DWF tidak dilindungi password; gunakan `converter.LoadOptions.Password` (yang memungkinkan Anda memberikan password untuk file terenkripsi) jika diperlukan.  
- **Font Hilang** – sematkan font yang diperlukan dalam DWF sumber atau sediakan folder font melalui `converter.Options.FontsPath` (yang menentukan direktori berisi font yang dibutuhkan untuk rendering).  
- **Kesalahan Out‑of‑Memory** – aktifkan mode streaming (`converter.Options.UseStream = true`; `UseStream` mengaktifkan mode streaming untuk memproses file dalam potongan, mengurangi penggunaan memori).
