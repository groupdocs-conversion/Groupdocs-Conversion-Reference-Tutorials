## 구현 가이드

### GroupDocs.Conversion을 사용하여 DWF를 HTML로 변환하는 방법
`Converter`는 변환을 위한 소스 파일을 나타내는 핵심 클래스입니다.  
`Convert` 메서드는 변환 프로세스를 실행하고 결과를 지정된 대상에 기록합니다.  
`WebConvertOptions`는 페이지 크기, 이미지 품질, CSS 삽입 등 HTML 출력 설정을 지정합니다.

`Converter` 클래스로 DWF 파일을 로드하고 `Convert` 메서드를 호출하여 API가 HTML을 생성하도록 `WebConvertOptions` 객체를 전달합니다. 이 한 줄 호출은 래스터화, 벡터 변환 및 스타일시트 생성을 자동으로 처리합니다.

`WebConvertOptions`는 출력 형식과 페이지 크기, 이미지 품질, CSS 삽입과 같은 선택적 설정을 정의합니다.

```csharp
string inputFilePath = Path.Combine("YOUR_DOCUMENT_DIRECTORY", "sample.dwf");
string outputFolder = "YOUR_OUTPUT_DIRECTORY";
string outputFile = Path.Combine(outputFolder, "dwf-converted-to.html");
```  

### 1단계: 입력 및 출력 경로 정의
소스 DWF 파일이 위치한 경로와 결과 HTML을 저장할 경로를 지정합니다.

```csharp
using (var converter = new Converter(inputFilePath))
{
    // Initialize options to convert to HTML format
    var options = new WebConvertOptions();
    
    // Perform the conversion and save as an HTML file
    converter.Convert(outputFile, options);
}
```  

### 2단계: 변환 실행
`converter.Convert`를 `WebConvertOptions`와 함께 호출합니다. 이 메서드는 결과를 직접 디스크에 스트리밍하여 500 MB 이상의 파일에서도 메모리 사용량을 낮게 유지합니다.

## 성능 고려 사항
대용량 CAD 도면을 변환할 때 다음 팁을 기억하세요:
- **Resource Optimisation** – `converter.Options.MemoryLimit`를 활성화하여 (컨버터가 할당할 수 있는 최대 메모리를 제한) RAM 사용량을 256 MB로 제한합니다.  
- **Batch Processing** – 파일을 10–20개씩 배치로 묶어 I/O 오버헤드를 최소화합니다.  
- **Asynchronous Execution** – 변환 호출을 `Task.Run`으로 감싸 UI 스레드가 응답성을 유지하도록 합니다.  
- **Parallelism** – `converter.Options.ThreadCount`를 증가시켜 (변환 중 동시에 사용되는 스레드 수를 결정) 배치 작업 속도를 높입니다.  

이러한 방식을 따르면 일반적인 서버 제한 내에서 빠른 변환 속도를 유지할 수 있습니다.

## 일반적인 문제 및 해결책
- **Blank Pages in Output** – DWF 파일이 비밀번호로 보호되지 않았는지 확인하고, 필요한 경우 `converter.LoadOptions.Password`를 사용하여 (암호화된 파일에 대한 비밀번호를 제공) 설정합니다.  
- **Missing Fonts** – 필요한 글꼴을 소스 DWF에 포함하거나 `converter.Options.FontsPath`를 통해 글꼴 폴더를 제공하여 (렌더링에 필요한 글꼴이 들어 있는 디렉터리를 지정) 설정합니다.  
- **Out‑of‑Memory Errors** – 스트리밍 모드를 활성화합니다 (`converter.Options.UseStream = true`; `UseStream`는 파일을 청크 단위로 처리하여 메모리 사용량을 줄이는 스트리밍 모드)하여 파일을 청크로 처리합니다.
